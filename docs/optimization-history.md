# wuji-reader 墨水屏优化历程与软件特性（发布文档素材）

> 用于 README「特性 / 优化历程」章节与软件内「关于」页。版本基线：0.20.0（versionCode 20）。

## 一、为什么重写（项目起源）

上游 wuji-tauri 是 Tauri + Vue 3 的跨平台阅读器，依赖 WebView 运行。
目标设备（Boyue Lemon Read Plus 等 Android 6 / API 23 墨水屏）出厂 WebView 约为 Chrome 44：
- **Vue 3 依赖 Proxy，Chrome 49 以下无法运行，且 Proxy 语义无法 polyfill**；
- 厂商锁死 WebView 不可升级；
- 结果：原版「装得上 → 运行即弹停止运行 ×3 → 退回桌面」。

**结论：在此类设备上 WebView 路线无解。** 故以纯 Java 原生重写
（OkHttp + Jsoup + Glide，minSdk 23，无 WebView、无 native 库），
功能对齐上游的「订阅源 + 小说/漫画/新闻阅读」核心，专为墨水屏与遥控器操作重构交互。

## 二、墨水屏优化历程（按版本）

| 版本 | 优化内容 |
|---|---|
| v1–v4 | **原生重写**：弃 WebView，纯 Java 架构；GBK 站点编码嗅探（`bytes()` → Jsoup 解析，避免 OkHttp 按 UTF-8 硬解乱码）；http 明文源 `usesCleartextTraffic` |
| v5–v7 | **源体系**：小说 7 源 + 漫画多源移植（统一 `BookExtension`/`ComicExtension` 契约）；酷喔读书等源实测接入 |
| v8–v9 | **源管理**：启用/停用/排序/自定义 Legado 书源 JSON 导入 |
| v10–v12 | **遥控器适配**：原生 `forwardKey()` 走 `window.dispatchEvent`（不经 document，PC 键盘测不出）→ 统一 `tvRemote` 挂 window 监听；九宫格分区手势；**全局字号**（`fontScale` 注入，布局零改动全量缩放，默认 30sp）；**core library desugaring**（API 23 上跑 jsoup 1.17.2 的 `java.util.stream`，否则类加载期崩溃） |
| v13–v16 | **阅读体验**：九宫格改为「上一页/下一页」（非切章）；阅读背景色四档；自动滚动（速度可调、到底续章）；翻页到本章顶/底自动切上下章；新闻能抓正文直接读（不弹链接弹窗）；相关报道改为可点条目 + 九宫格在报道区让位（视口/内容坐标换算） |
| v17 | **Bing 检索修复**：Bing 改版后结果块为 `<a><h2>` 结构（旧选择器 `h2 a` 静默选空）→ 改 `a:has(h2)` 兼容，相关报道恢复可点开 |
| v18–v19 | **摘要聚合与防跑偏**：抓不到正文时多源摘要加长；检索词改用最初热搜词（用文章标题检索会被分词成单字，返回字典释义）；**bigram 相关性闸门**（至少 2 个相邻双字重合才收录），宁可 0 条不显示垃圾 |
| v20 | **漫画翻页回顶 + 顶置微调**：放大翻页改为左上角焦点（原来画面中心焦点会停在中段）；菜单新增「顶置微调」可调顶点偏移（默认左移 3px、下移 3px），消除扫描件白边 |

## 三、软件特性（发布版）

- **纯原生、无 WebView**：Android 6（API 23）可用，不依赖系统 WebView 版本
- **墨水屏交互**：
  - 全局字号可调（22–44，默认 30），全部界面文字一次缩放
  - 遥控器九宫格（3×3 分区，动作可自定义：翻页/目录/清屏/缩放等）
  - 纯黑白无动画、大点击区、可拖拽快速滚动条
  - 阅读背景色四档（白/米黄/护眼绿/灰）
- **小说阅读**：章节目录、自动滚动（三档速度、到底自动续章）、字号/背景独立调节、阅读进度记忆
- **漫画阅读**：逐图翻页（单图全刷）、双指缩放（1–50×）、单指拖动边界钳制、双击 2.5×、翻页保持倍数、顶置微调
- **新闻热榜**：多榜单（知乎/微博/百度/抖音/贴吧等）；正文抓取（站点专用选择器 + 密度算法兜底）；抓不到时相关报道可点开 + 多源摘要聚合（带相关性过滤）
- **源管理**：Legado 书源 JSON 导入（**发布版不含任何内置源**）、启用/停用/排序、自定义源删除
- **合规**：GPL-3.0 开源，基于 wuji-tauri 衍生，源码随仓库完整分发

## 四、与上游的差异（GPL「标注修改」）

1. 技术栈变更：Tauri/Vue/Rust + WebView → 纯 Java 原生（无 WebView、无 native 库）
2. 目标设备变更：桌面/移动通用 → Android 6 墨水屏 + 遥控器优先
3. 模块裁剪：去除影视、美图模块
4. 交互重构：九宫格、全局字号、墨水屏配色、顶置微调等（详见历程）
5. 源策略变更：发布版**不含任何内置源**，全部由用户自行导入 Legado 书源 JSON
6. 名称变更：发布名 `wuji-reader`，非官方衍生版
