## 六、爬虫合规边界分析（参照国内判例）

判例来源：[Crawler_Illegal_Cases_In_China](https://github.com/xushijiu/Crawler_Illegal_Cases_In_China) 及公开裁判文书。

**司法边界（已核实的判例结论）**：
1. **单纯爬取公开数据不构成犯罪**——山西吕梁案明确：对未设技术障碍的公开网页做常规采集，不存在"非法侵入、破坏系统"情形；司法评判重点在"是否违反网站协议/破坏技术防护"与"后续如何利用"。
2. **刑事红线**（均有实刑判例）：
   - 破解验证码/规避安全验证 → 提供侵入计算机信息系统程序罪（上海普陀陈某案，爬取 8 亿条数据案）
   - 抓取数据贩卖获利 → 非法获取计算机信息系统数据罪（多起，含爬取"起点"小说供免费阅读获利千万案）
   - 高频请求致目标宕机 → 破坏计算机信息系统罪（每秒 183 次请求致超算崩溃案）
   - 抓取公民个人信息 → 侵犯公民个人信息罪
3. **免责关键**：公开性 + 不突破防护 + 不牟利 + 不贩数据。

**本项目的对应设计**：

| 判例红线 | 本项目状态 |
|---|---|
| 破解验证码/反爬对抗 | ✅ 代码不含任何验证码识别、签名破解逻辑（仅常规 UA/Referer 请求头） |
| 数据贩卖/接口输出 | ✅ 无任何数据导出给第三方的接口，纯本地阅读 |
| 内置盗版内容 | ✅ 零内置源、零预置内容（发布版已物理移除） |
| 高频压测 | ✅ 无并发批量抓取设计 |
| 公民信息 | ✅ 无个人信息采集/存储/上传 |
| 牟利 | ✅ 无广告、无收费、无会员 |
| 用户自配源的责任划分 | ✅ 软件为中性空壳框架，数据源由用户自行配置；README 与关于页均已声明"仅供学习研究、不提供侵权内容、后果自负" |

**结论**：软件本体处于合规区间；残余风险在用户自配源的抓取行为，
已通过"空壳设计 + 显著声明 + 非营利"三重设计将提供方责任降至最低。
